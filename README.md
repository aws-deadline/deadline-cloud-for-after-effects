# `deadline-cloud-for-after-effects` — DEPRECATED PyPI package

> ⚠️ **This PyPI package is deprecated.**
>
> AWS Deadline Cloud for After Effects is now delivered by the shared
> Deadline Cloud submitter installer — a separate PyPI adaptor package
> is no longer required. Installing this PyPI package into a Worker
> Agent environment is also known to break the Worker.
>
> Release 0.99.0 is a tombstone: it contains no executable code, no
> command-line entry points, and no runtime dependencies. Importing it
> only raises a `DeprecationWarning`.
>
> **What to do instead**
>
> Uninstall this package and follow the [AWS Deadline Cloud User
> Guide][installer] to install the shared submitter.

[installer]: https://docs.aws.amazon.com/deadline-cloud/latest/userguide/submitter.html
